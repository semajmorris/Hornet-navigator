ABOUT THE PROJECT

Built by a student, for students.

Hornet Navigator is an independently developed student project designed to create a simpler and more visual way to navigate Alabama State University's campus.

The goal is to combine official campus information with practical student knowledge so Hornets can find not only buildings, but the resources they actually need.

Independent Student Project

Hornet Navigator is not an official Alabama State University website or service.
